# What is PropAI Pulse? A WhatsApp-native real estate intelligence engine

PropAI Pulse is an AI workspace for Indian real estate brokers. It is built for the place where broker inventory actually lives: WhatsApp groups, direct chats, forwarded listings, and messy broker dumps. Instead of asking brokers to repost inventory into a portal first, PropAI Pulse reads the raw message stream, separates listings from requirements, normalizes localities, and publishes clean searchable market data.

If you want the shortest answer: PropAI Pulse turns WhatsApp chaos into structured broker intelligence.

## What PropAI Pulse does

PropAI Pulse is not a consumer property portal. It is a broker workflow engine.

It ingests raw WhatsApp exports and live broker messages, then applies a parsing pipeline that:

- strips boilerplate and system noise
- detects whether a message is a listing or a requirement
- extracts structured fields like BHK, area, price, locality, city, furnishing, and deal type
- normalizes Mumbai locality aliases like BKC, JVPD, Linking Road, and Carter Road into canonical market names
- stores the result as clean records that can be searched, matched, and routed

Internally, the extraction layer is centered around the real repo schema, including `ExtractedLeadSchema`, `REQUIREMENT_SIGNALS`, and location alias handling in the Mumbai parser layer. That matters because it keeps the output consistent instead of letting every screen reinterpret the same broker message differently.

## How it works

The workflow is simple:

1. Broker inventory arrives in WhatsApp.
2. PropAI parses the message stream.
3. Listings and requirements are split into canonical objects.
4. Localities are normalized into market belts.
5. Clean records are published to the public site and broker workspace.
6. Brokers can search, match, and follow up faster.

That means the public site can show real inventory and the internal app can stay operational around the same source of truth.
